# Contributing

Thanks for your interest in improving this project.

## How to contribute

1. Fork the repository and create a feature branch.
2. Keep changes focused and easy to review.
3. Add or update a runnable student scenario when behavior changes.
4. Run at least one representative script before opening a PR:

```bash
python3 Student_EE.py
```

5. Open a pull request describing:
   - What changed
   - Why it changed
   - Any assumptions or limitations

## Style notes

- Follow existing Python style and naming conventions.
- Keep course database edits accurate and traceable.
- Prefer small, incremental PRs.
